## Python

```python
import numpy as np

def energy_efficiency(throughput, power):
    return throughput / np.maximum(power, 1e-12)

throughput = np.array([10.2, 12.8, 15.1])
power = np.array([2.1, 2.4, 2.8])

print(energy_efficiency(throughput, power))
```
